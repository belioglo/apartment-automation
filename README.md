# Apartment Automation

Учебный проект автоматизации обработки заявок для команды управления апартаментами.

## Возможности

- Получение заявок из Google Sheets через API.
- Проверка обязательных полей и срочности.
- Поиск возможных дубликатов.
- Локальная классификация по ключевым словам.
- Определение приоритета по указанной срочности.
- Сохранение результатов на отдельную вкладку Results.
- Формирование локального JSON-отчёта.

## Технологии

Python, Google Sheets API, gspread, pytest.

## Запуск



python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env

1. Включите Google Sheets API в Google Cloud.
2. Создайте сервисный аккаунт и сохраните его JSON-ключ
   в корне проекта как credentials.json.
3. Предоставьте аккаунту права редактора на Google-таблицу.
4. Укажите ID таблицы в GOOGLE_SHEET_ID в файле .env.
5. Создайте вкладку Requests со столбцами:
   id, object, description, urgency, status.
6. Заполните строки тестовыми данными.
python -m src.main
python -m src.main

Результаты записываются на вкладку Results и в папку data.
Внимание: вкладка Results полностью перезаписывается.

## Ограничения

Каждый запуск обрабатывает все заявки заново.
Совпадение объекта и описания помечает обе заявки как возможные дубликаты.
Такие заявки пропускают классификацию.

Текущая версия использует правила, а не нейросеть.
Интеграция с OpenAI API планируется отдельно.

## Безопасность

Используйте синтетические данные.
Не публикуйте .env и credentials.json.
